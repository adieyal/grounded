# First Response Shape

The first reply should be a small plan, not a full model.

Recommended structure:
1. State the slice you think the user wants to model.
2. Say what evidence you will inspect.
3. Say that you will ask a short sequence of boundary, comparison, and analysis questions.
4. Ask the first narrowing question.

The goal is to make the user comfortable correcting the boundary early, before the model gets too broad or too abstract.
