# Interlinking Guidance

Links are for ownership, constraint, evidence, and navigation.

Use links to show:
- which unit owns a meaning
- which rule constrains which concept or entity
- which example demonstrates which rule
- which derived unit depends on which canonical parent

Avoid:
- redundant links that repeat the same relationship
- dense cross-linking between every adjacent noun
- links that exist only because the name sounds related

Good linking makes the model easier to trust and easier to expand. If a link does not answer a future question, it probably does not belong yet.
